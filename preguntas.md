# Banco de preguntas para repasar a Roser

Se corre con `uv run python scripts/repaso.py`. **Editable por cualquiera**: si
en el grupo aparece una pregunta nueva que se repite, añadila acá.

Formato: una pregunta por línea, con `-`. Las secciones importan: las de
`## Escalado` **tienen que** disparar `escalar()`, y si alguna no lo hace, no se
despliega.
